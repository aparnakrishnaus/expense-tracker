## Fiscal Atelier

### A creative studio for managing finances.

Fiscal Atelier is a modern full-stack expense tracker built using **React.js** and **Django REST Framework**.

The project focuses on creating a premium fintech-inspired user experience with interactive dashboards, expense analytics, animations, and responsive design.

* Python
* Django
* Django REST Framework

* SQLite

## Features

* Expense tracking
* Dashboard with financial summaries
* Expense analytics and charts
* Wallet management
* Responsive design
* Animated UI interactions
* REST API powered by Django REST Framework
